## PART A — STRAIGHT LINE GRAPHS (Chapter 16)

### 1. The Cartesian plane

- Two number lines cross at the **origin** `(0 ; 0)`: the horizontal **x-axis** and the vertical **y-axis**.
- A point is written as an ordered pair **(x ; y)** — **across first, then up/down**.
- The axes cut the plane into four **quadrants**:

| Quadrant | x | y | Example |
|---|---|---|---|
| I (top right) | + | + | (3 ; 2) |
| II (top left) | − | + | (−3 ; 2) |
| III (bottom left) | − | − | (−3 ; −2) |
| IV (bottom right) | + | − | (3 ; −2) |

- Points on the **x-axis** have `y = 0`; points on the **y-axis** have `x = 0`.

### 2. The equation of a straight line

**Standard form:  y = mx + c**

- **m = the gradient (slope)** — how steep the line is and in which direction it slopes.
- **c = the y-intercept** — where the line cuts the y-axis, i.e. the point `(0 ; c)`.

> Always rewrite an equation into `y = mx + c` form before reading off m and c.
> e.g. `2y = 6x − 8` → divide by 2 → `y = 3x − 4`, so `m = 3` and `c = −4`.
> e.g. `3x + y = 5` → `y = −3x + 5`, so `m = −3` and `c = 5`.

### 3. Gradient

$$m = \frac{\text{rise}}{\text{run}} = \frac{\text{change in } y}{\text{change in } x} = \frac{y_2 - y_1}{x_2 - x_1}$$

**Worked example:** gradient of the line through A(1 ; 2) and B(5 ; 10)

```
m = (10 − 2) / (5 − 1) = 8 / 4 = 2
```

**Types of gradient**

| Gradient | What the line looks like |
|---|---|
| m > 0 (positive) | Rises from left to right ( / ) |
| m < 0 (negative) | Falls from left to right ( \ ) |
| m = 0 | **Horizontal** line, equation `y = c` |
| m undefined | **Vertical** line, equation `x = a` (you would divide by 0) |

- The **bigger the |m|**, the **steeper** the line. `y = 4x` is steeper than `y = ½x`.
- **Parallel lines have equal gradients** (`m₁ = m₂`).
- Lines with the same `c` cut the y-axis at the same point.

### 4. Special lines to memorise

| Equation | Line |
|---|---|
| `y = 3` | Horizontal, 3 units above the x-axis |
| `x = −2` | Vertical, 2 units left of the y-axis |
| `y = x` | Diagonal through the origin, m = 1 |
| `y = −x` | Diagonal through the origin, m = −1 |
| `y = 2x` | Through the origin (c = 0) |

### 5. Drawing a straight line graph

**Method 1 — Table of values** (safest, works for every line)

Draw `y = 2x − 1`:

| x | −1 | 0 | 1 | 2 |
|---|---|---|---|---|
| y | −3 | −1 | 1 | 3 |

Plot the points, join with a **ruled straight line**, and **label the line with its equation**.

**Method 2 — Dual-intercept method** (fastest when c ≠ 0)

For `y = 2x − 4`:
- **y-intercept:** let `x = 0` → `y = −4` → point `(0 ; −4)`
- **x-intercept:** let `y = 0` → `0 = 2x − 4` → `x = 2` → point `(2 ; 0)`
- Plot the two intercepts and rule the line through them.

**Method 3 — Gradient and intercept**
Plot `(0 ; c)`, then from that point move according to `m = rise/run` (e.g. m = 3/2: up 3, right 2) and plot a second point.

### 6. Finding the equation from a graph

1. Read off the **y-intercept** → that is **c**.
2. Choose **two clear points** on the line and calculate **m**.
3. Substitute both into `y = mx + c`.

**Worked example:** a line cuts the y-axis at −1 and passes through (2 ; 5).

```
c = −1
m = (5 − (−1)) / (2 − 0) = 6/2 = 3
∴ y = 3x − 1
```

If you are given **two points only**: find m first, then substitute **one** point into `y = mx + c` to solve for c.
Through (1 ; 4) and (3 ; 10): `m = 6/2 = 3`; then `4 = 3(1) + c` → `c = 1` → `y = 3x + 1`.

### 7. Checking whether a point lies on a line

Substitute the point into the equation — if **LHS = RHS**, the point lies on the line.

Does (3 ; 5) lie on `y = 2x − 1`?  `2(3) − 1 = 5` ✓ Yes.
Does (4 ; 6) lie on `y = 2x − 1`?  `2(4) − 1 = 7 ≠ 6` ✗ No.

### 8. Point of intersection

Two lines cross where their x- and y-values are the same. Read the coordinates off the graph, or solve the equations simultaneously.

`y = x + 1` and `y = −x + 5` → `x + 1 = −x + 5` → `2x = 4` → `x = 2`, `y = 3` → intersection **(2 ; 3)**.

### 9. Interpreting real-life graphs

- **Linear (straight) graph** = **constant rate of change** (constant speed, fixed rate per hour, etc.).
- The **gradient tells the rate** — e.g. R/hour, km/h, cost per item.
- The **y-intercept is the fixed/starting value** — e.g. a call-out fee, a starting distance, a deposit.
- **Discrete data**: separate points only (number of learners, number of cars) — plot dots, do **not** join.
- **Continuous data**: any value in between is possible (time, distance, mass) — join with a solid line.
- A **horizontal section** means "no change" (stationary, cost stays the same).

**Example:** A plumber charges `C = 250h + 400`, where h = hours.
- `400` = fixed call-out fee (y-intercept)
- `250` = cost per hour (gradient)
- For 3 hours: `C = 250(3) + 400 = R1 150`

## PART B — DATA HANDLING (Chapter 19 + extra notes)

### 1. The data-handling cycle

1. **Pose a question**
2. **Collect** the data
3. **Organise** it (tally / frequency table)
4. **Represent** it (graph)
5. **Analyse** it (mean, median, mode, range, spread)
6. **Interpret and report** (draw conclusions, answer the question)

### 2. Types of data

| Type | Meaning | Example |
|---|---|---|
| **Qualitative (categorical)** | Descriptions, words | Eye colour, favourite sport |
| **Quantitative** | Numbers | Height, test marks |
| — **Discrete** | Counted, exact values | Number of siblings, goals scored |
| — **Continuous** | Measured, any value in a range | Mass, time, length |
| **Primary data** | You collected it yourself | Your own class survey |
| **Secondary data** | Collected by someone else | Newspaper or Stats SA figures |

### 3. Sampling and bias

- **Population** = every member of the group being studied.
- **Sample** = the smaller part actually surveyed. It must be **representative** and **random**.
- **Bias** = anything that makes the result unfair or one-sided:
  - a sample that is too small or not representative (e.g. only asking your friends),
  - **leading questions** ("Don't you agree that…?"),
  - questions that are ambiguous, embarrassing, or have overlapping options.
- A good questionnaire question is short, clear, unbiased, and has options that do not overlap.

### 4. Organising data

**Tally and frequency table**

| Score | Tally | Frequency |
|---|---|---|
| 5 | \|\|\|\| | 4 |
| 6 | \|\|\|\| \|\| | 7 |
| 7 | \|\|\| | 3 |
| | **Total** | **14** |

**Grouped data** — used when there are many different values. Use equal intervals that do **not** overlap: `0–9, 10–19, 20–29 …` or `0 ≤ x < 10`, `10 ≤ x < 20`.

**Stem-and-leaf display** — keeps every original value.

```
Stem | Leaf
  1  | 2 5 8        →  12, 15, 18
  2  | 0 3 3 7      →  20, 23, 23, 27
  3  | 1 4          →  31, 34
Key: 1 | 2 means 12
```
Always give a **key**. The data is automatically in order, which makes finding the median easy.

### 5. Representing data — choosing the right graph

| Graph | Use it for |
|---|---|
| **Bar graph** | Categorical or discrete data; **bars have gaps** |
| **Double bar graph** | Comparing two groups (e.g. boys vs girls) |
| **Histogram** | Grouped continuous data; **bars touch**, no gaps |
| **Pie chart** | Showing parts of a whole (percentages of a total) |
| **Broken-line graph** | Showing a trend over **time** |
| **Scatter plot** | Relationship between **two** variables |

**Pie chart angles:**  angle = (frequency ÷ total) × 360°
e.g. 12 of 40 learners walk to school → `12/40 × 360° = 108°`.
As a percentage: `12/40 × 100 = 30%`.

Every graph must have: a **title**, **labelled axes** (with units), a suitable **scale starting at 0**, and a **key** if there is more than one data set.

### 6. Measures of central tendency

| Measure | How to find it | Watch out |
|---|---|---|
| **Mean** (average) | `sum of all values ÷ number of values` | Strongly affected by outliers |
| **Median** (middle) | **Arrange in order first**, then take the middle value | Best when there are outliers |
| **Mode** (most) | The value that appears most often | Can be none, one, or more than one |

**Median rule:** with `n` values, the median is in position `(n + 1)/2`.
- Odd n (e.g. 7 values): position 4 = the middle value.
- Even n (e.g. 8 values): average the 4th and 5th values.

**Worked example:** 4, 7, 7, 9, 13
- Mean = `(4+7+7+9+13)/5 = 40/5 = 8`
- Median = 7 (3rd of 5 values)
- Mode = 7

**Working backwards (common exam question):** The mean of 5 numbers is 12. Four of them are 10, 14, 9, 15. Find the fifth.
`Total = 12 × 5 = 60`; `10+14+9+15 = 48`; fifth number `= 60 − 48 = 12`.

**Mean from a frequency table:** mean = `Σ(value × frequency) ÷ Σfrequency`.
**Grouped data:** you can only give the **modal class** (the interval with the highest frequency) and the **interval containing the median**.

### 7. Measures of dispersion (spread)

- **Range = maximum − minimum.** A big range means the data is widely spread.
- **Outlier** = a value far away from the rest. It pulls the **mean** but hardly moves the **median**.
- **Quartiles** split the ordered data into four equal parts:
  - **Q1** (lower quartile) = median of the lower half
  - **Q2** = the median
  - **Q3** (upper quartile) = median of the upper half
- **Interquartile range (IQR) = Q3 − Q1** — the spread of the middle 50%.

**Five-number summary:** minimum, Q1, median, Q3, maximum → used to draw a **box-and-whisker diagram**.

**Worked example:** 2, 4, 5, 7, 8, 10, 12, 15, 18 (9 values, already in order)
- Min = 2, Max = 18, Range = 16
- Median (5th value) = 8
- Lower half: 2, 4, 5, 7 → Q1 = `(4+5)/2 = 4,5`
- Upper half: 10, 12, 15, 18 → Q3 = `(12+15)/2 = 13,5`
- IQR = `13,5 − 4,5 = 9`

### 8. Which measure is "best"?

- Data with an **extreme outlier** (e.g. salaries where one person earns far more) → use the **median**.
- **Categorical** data (favourite colour, shoe size to stock) → use the **mode**.
- Fairly even, no outliers → the **mean** uses every value and is usually best.

### 9. Interpreting and misleading graphs

Be ready to explain **why a graph is misleading**:
- The vertical axis **does not start at 0**, or the axis is broken → differences look exaggerated.
- **Unequal or uneven scale** intervals.
- 3-D effects or pictures of different sizes that distort the comparison.
- No labels, no title, or no key.
- A conclusion drawn from **too small or biased a sample**.

When asked to "**comment on**" or "**compare**" data: mention **centre** (mean/median), **spread** (range/IQR), and anything unusual (**outliers, trend**) — and say what it means in the context of the question.

## QUICK-REFERENCE FORMULA SHEET

```
Straight lines
  y = mx + c                m = gradient, c = y-intercept
  m = (y₂ − y₁)/(x₂ − x₁) = rise/run
  y-intercept: let x = 0        x-intercept: let y = 0
  Horizontal: y = c (m = 0)     Vertical: x = a (m undefined)
  Parallel lines: m₁ = m₂

Data handling
  Mean   = sum of values ÷ number of values
  Median = middle value of ORDERED data, position (n + 1)/2
  Mode   = most frequent value
  Range  = max − min
  IQR    = Q3 − Q1
  Pie chart angle = (frequency ÷ total) × 360°
  Percentage = (frequency ÷ total) × 100
```

## EXAM TIPS (1 hour, 50 marks — about 1 minute per mark)

- Use a **ruler and pencil** for every graph; label the axes, the intercepts and the line's equation.
- **Show all working** — method marks are given even when the final answer is wrong.
- Always **rewrite into `y = mx + c`** before reading off the gradient.
- **Order the data** before finding the median or quartiles — the most common lost mark.
- Check the **units** and whether the answer must be rounded (e.g. to one decimal place).
- Read "comment on" / "explain" questions carefully — they need a **sentence in context**, not just a number.
- Leave the longest interpretation question for last if you are short of time, but attempt every question.
